# Zenler FAQ Support Agent

A local Zenler-styled FAQ support app that searches 677 refined FAQ answers and responds like an animated live support agent.

## Run Locally

```bash
pnpm install
pnpm start
```

Then open `http://127.0.0.1:5173/`.

## Included Source Content

- `Zenler_FAQ_Bank_MERGED_REFINED.docx`
- `Zenler_FAQ_Content_Analytics_Report.pdf`
- `assets/Logo_Zenler.png`

The app uses `src/data/faqs.js`, generated from the Word FAQ bank.
